# Pomi logo

The approved Pomi identity is **B — Terminal** from the **Set up oc CLI Bash
completion** design session: a forest-green `>_` terminal prompt
with a leaf, and the rounded lowercase `pomi` wordmark.

- [pomi-logo.png](pomi-logo.png): isolated color logo and wordmark on white,
  prepared from the approved concept for documentation use with the built-in
  image generation tool. [Extraction prompt](extraction-prompt.txt).
- [approved-concept-source.png](approved-concept-source.png): unmodified
  comparison sheet recording the approved design in its center column. The
  other columns are alternative concepts, not the selected identity.

Keep the master here. The identical published copy lives in
[`src/docs/reference/branding/assets/logo/pomi/pomi-logo.png`](../../../../src/docs/reference/branding/assets/logo/pomi/pomi-logo.png).
The CLI walkthrough, Remote Management reference, and branding page use that
copy. Preserve the logo's proportions and colors when displaying it; its white
background also keeps the wordmark legible in dark documentation themes.

The executable and documented command examples use `oc`.
